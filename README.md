# 合唱パート練習アプリ

校歌・「地球へ」のパート練習用音源を、クリックひとつで再生できるHTMLアプリです。

## 使い方（オフライン）

`index.html` と `校歌/`・`地球へ/` フォルダをまとめてUSBメモリなどにコピーし、
`index.html` をダブルクリックしてブラウザで開くだけで使えます。インターネット接続は不要です。

## 使い方（オンライン / GitHub Pages）

このリポジトリを GitHub Pages で公開すると、以下のURLからスマホ・タブレットでもそのまま使えます。

```
https://<ユーザー名>.github.io/gassyo/
```

## 音源を追加・差し替えたいとき

1. `校歌/` または `地球へ/` フォルダの中の mp3 を差し替える（同じファイル名にする）
2. 曲や構成を変える場合は `index.html` 内の `SONGS` の定義（ファイル名・ラベル）を編集する
3. オンライン版に反映するには、変更をコミットして push する

```bash
git add .
git commit -m "音源を更新"
git push
```

## 機能

- 曲（校歌／地球へ）をタブで切り替え
- 全パート／ピアノ伴奏のみ／各パート単体／パート練習用（自分のパートが聞き取りやすいバランス）をボタンで再生
- 再生速度変更（0.7〜1.1倍）、5秒早送り・巻き戻し、ループ再生、音量調整
- 前回の速度・音量設定を記憶（ブラウザのlocalStorage）

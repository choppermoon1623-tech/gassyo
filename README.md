# 合唱パート練習アプリ

校歌・「地球へ」のパート練習用音源を、クリックひとつで再生できるHTMLアプリです。

## 使い方（オフライン）

`index.html` と `校歌/`・`地球へ/` フォルダをまとめてUSBメモリなどにコピーし、
`index.html` をダブルクリックしてブラウザで開くだけで使えます。インターネット接続は不要です。

## 使い方（オンライン / GitHub Pages）

このリポジトリを GitHub Pages で公開すると、以下のURLからスマホ・タブレットでもそのまま使えます。

```
https://<ユーザー名>.github.io/gassyo/
```

## 音源を追加・差し替えたいとき

1. `校歌/` または `地球へ/` フォルダの中の mp3 を差し替える（同じファイル名にする）
2. 曲や構成を変える場合は `index.html` 内の `SONGS` の定義（ファイル名・ラベル）を編集する
3. オンライン版に反映するには、変更をコミットして push する

```bash
git add .
git commit -m "音源を更新"
git push
```

`index.html` の見た目や機能を変更したときは、`sw.js` 先頭の `CACHE` の値（例: `gassyo-v2`）を1つ増やしてからpushしてください。PWAとしてキャッシュ済みの端末にも変更が反映されます（増やし忘れると、変更前の画面がずっと表示され続けることがあります）。

## 機能

- 曲（校歌／地球へ）をタブで切り替え
- 全パート／ピアノ伴奏のみ／各パート単体／マイナスワン音源（自分のパートを抜いた伴奏）をボタンで再生
- 再生速度変更（0.7〜1.1倍）、5秒早送り・巻き戻し、曲全体のループ再生、音量調整
- 区間リピート（A-Bループ）：難しいフレーズだけをマーカーで指定して繰り返し再生
- 練習チェックリスト：パートごとに「聞いた／歌えた」を記録（この端末のみ・自己申告用。リセットボタンあり）
- 前回の速度・音量設定を記憶（ブラウザのlocalStorage）
- オンライン版（GitHub Pages）はPWA対応。一度アクセスして再生した音源はブラウザにキャッシュされ、次回以降ネット接続なしでも再生可能（オフラインコピー版は元々ネット不要）
